# SPS-RTAFNC

ระบบจัดซื้อจัดจ้าง วิธีเฉพาะเจาะจง (Special Procurement System) — ต้นแบบเว็บแอปสำหรับ
บริหารงานพัสดุของ วิทยาลัยพยาบาลทหารอากาศ ใช้งานได้ทุกอุปกรณ์ (มือถือ แท็บเล็ต คอมพิวเตอร์)

🔗 **ใช้งานจริง:** https://anuchit1tube168-cmd.github.io/SPS-RTAFNC/

## ฟีเจอร์หลัก

- เข้าสู่ระบบ 4 บทบาท
- แดชบอร์ดสรุปจำนวนเอกสาร มูลค่ารวม และสถานะงาน
- ใบขอซื้อ/ขอจ้าง แบบการ์ดและตาราง พร้อมค้นหา/กรอง
- สร้างเอกสารใหม่พร้อมรายการพัสดุหลายรายการ
- Workflow สถานะงาน (ฉบับร่าง → ตรวจสอบ → เห็นชอบ → พิจารณา → สั่งซื้อ → ตรวจรับ → เสร็จสมบูรณ์)
- พิมพ์/บันทึก PDF เอกสารราชการ และ Export CSV
- ทะเบียนผู้ขาย/ผู้รับจ้าง, Audit log, ตั้งค่าหน่วยงาน
- รองรับการติดตั้งเป็นแอป (PWA) และใช้งานได้ทุกอุปกรณ์

## เทคโนโลยี

Static frontend — HTML + CSS + Vanilla JavaScript ไฟล์เดียว (`index.html`) ไม่มี build step
เก็บข้อมูลผ่าน `localStorage` โฮสต์บน GitHub Pages ได้ทันที

## การพัฒนา

ไม่ต้องติดตั้ง dependency ใด ๆ เปิด `index.html` ในเบราว์เซอร์ได้เลย หรือรันเซิร์ฟเวอร์แบบ static:

```bash
python3 -m http.server
```

จากนั้นเปิด http://localhost:8000

รายละเอียดสถาปัตยกรรมและแนวทางการพัฒนาอยู่ใน [CLAUDE.md](./CLAUDE.md)

## หมายเหตุ

เวอร์ชันนี้เป็น Static Frontend Prototype ข้อมูลเก็บในเครื่องผู้ใช้ก่อน เหมาะสำหรับทดลอง
Flow/UX ก่อนต่อฐานข้อมูลจริง เช่น Google Sheets, Firebase, Supabase หรือ Backend API
